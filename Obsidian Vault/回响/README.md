# 回响宇宙知识库

本知识库用于长期维护“回响宇宙”的世界观、人物、势力、文明、遗迹、力量体系和视频内容资产。

## 当前核心定位

项目类型：原创大型科幻奇幻宇宙 IP  
核心风格：古老神秘、宇宙探索、多元宇宙  
核心问题：如果所有死亡都会留下回响，那么谁有权解释过去？

## 推荐工作顺序

1. 先维护数据库，不急于扩展新设定。
2. 每个新设定必须能回答：它属于哪个层级、服务哪条故事线、会制造什么冲突。
3. 每次新增人物、文明、势力或遗迹后，同步检查冲突与未解谜团。
4. 短视频优先使用“单一钩子 + 强视觉符号 + 一个悬念”的结构。
