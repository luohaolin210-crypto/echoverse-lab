# game-art-direction

## Purpose

建立可执行且可复用的项目视觉语言，避免默认素材和风格漂移。

## Trigger

画面不好看、视觉统一、风格探索、新项目启动或关键资产重做。

## Required Inputs

- visual style
- palette
- shape language
- perspective
- proportions
- lighting
- shadow policy
- material style
- UI style
- icon style
- VFX style
- forbidden styles
- reference board

## Workflow

1. 补齐视觉规格字段并建立 reference board。
2. 确定形状、比例、透视、材质和光影规则。
3. 用一屏关键场景验证风格。
4. 将 UI、图标、VFX 纳入同一套语言。
5. 用截图对照规格并记录偏差。

## Hard Gates

- 关键资产属于同一视觉系统。
- 焦点、层级、比例和光照规则稳定。
- Forbidden styles 已列出。

## Failure Conditions

- 只有风格形容词，没有执行规则。
- 资产各自好看但不一致。
- 用特效遮盖构图或材质问题。

## Evidence Required

- 视觉规格
- 参考板
- 关键场景前后对比
- 偏差清单

## Acceptance Criteria

- 陌生审阅者能复述视觉规则。
- 新资产加入不破坏整体统一。

## Forbidden Shortcuts

- 没有参考板就批量生成资产。
- 把分辨率和细节数量当作美术方向。
