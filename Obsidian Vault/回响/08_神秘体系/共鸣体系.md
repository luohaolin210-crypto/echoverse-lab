# 共鸣体系

## 核心定义

共鸣不是魔法，也不是纯科技，而是生命与远古回响之间的同步。

## 已有类型

1. 星辰共鸣
2. 记忆共鸣
3. 生命共鸣
4. 虚空共鸣
5. 神性共鸣

## 体系优势

共鸣可以同时支撑奇幻感、科幻解释和遗迹悬疑。它适合视频化，因为每种共鸣都能对应明确视觉效果和代价。

## 当前风险

共鸣过于万能时，会削弱科技、势力和主角选择的重量。

## 建议限制

1. 共鸣必须有代价。
2. 共鸣不能凭空创造信息，只能接触、放大或误读已有回响。
3. 神性共鸣必须高风险，不能成为常规战斗能力。
4. 阿尔文的回响感知前期必须不稳定，避免破坏悬疑。

## 待补

1. 五种共鸣等级。
2. 五种共鸣失控症状。
3. 共鸣训练方式。
4. 共鸣者在社会中的身份和法律地位。
